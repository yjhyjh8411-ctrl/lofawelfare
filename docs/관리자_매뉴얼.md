# LOFA 복지시스템 관리자 매뉴얼

**한국지방재정공제회 사내근로복지기금 신청 시스템**
최종 업데이트: 2026년 3월

---

## 관리자 접속

1. 시스템 URL 접속 후 로그인
2. 상단 네비게이션 바에서 **🔒 관리자** 버튼 클릭 (주황색 그라데이션)
3. 관리자 대시보드 진입

> 관리자 권한이 없는 계정에는 관리자 버튼이 표시되지 않습니다.
> 관리자 계정으로 로그인하면 자동으로 관리자 페이지(`/admin`)로 이동합니다.

---

## 관리자 대시보드 구성

관리자 페이지는 상단 헤더 + 별도 페이지로 구성되어 있습니다.

| 메뉴 | 경로 | 기능 |
|------|------|------|
| 관리자 홈 (신청서 심사) | /admin | 접수된 신청서 검토/승인/반려, 공지사항, 규정집, 알림 설정 |
| 직원 정보 관리 | /admin/employees | 직원 조회/수정/비밀번호 관리/퇴사처리 |
| 신청서 관리 | /admin/forms | 신청 양식 생성/편집/예산 그룹 설정 |
| 시스템 설정 | /admin/settings | Firebase 프로젝트 마이그레이션 |

### 관리자 헤더 기능
- **연도 필터**: 드롭다운으로 연도 선택 (올해 기본)
- **검색**: 사번 또는 성명으로 신청서 검색
- **전체 메일 발송** 버튼: 모든 활성 직원에게 일괄 이메일 발송

## 1. 신청서 심사

### 대시보드 통계
상단에 아래 현황이 카드로 표시됩니다:
- 검토 대기 건수 (노란 배경)
- 승인 건수 (초록 배경)
- 반려 건수 (빨간 배경)

### 필터 기능
- **상태 필터**: 전체 / 검토중 / 승인 / 반려
- **연도 필터**: 상단 드롭다운으로 연도 선택
- **검색**: 사번/성명/신청서명으로 검색

### 신청 목록 (테이블)
20건 단위로 페이지네이션되며, 아래 항목이 표시됩니다.

| 열 | 내용 |
|----|------|
| 신청일 | 신청서 제출 날짜 |
| 신청자(사번) | 이름과 사번 |
| 부서 | 소속 부서 |
| 신청서명 | 복지 항목 이름 |
| 상태 | 검토중/승인/반려 배지 |
| 승인금액 | 승인된 금액 (승인 시) |
| 반려사유 | 반려 사유 (반려 시) |
| 심사자 | 처리한 관리자 |
| 심사일 | 처리 날짜 |
| 관리 | 액션 버튼 |

### 승인 처리
1. 검토중 상태의 신청서에서 **승인** 버튼 클릭
2. 승인 모달이 열리며 신청자 정보와 신청 내용을 확인
3. 승인 금액 설정:
   - **전체 승인** 체크: 신청 금액 그대로 승인
   - 체크 해제 시: 수정된 금액 직접 입력 가능
4. **승인** 버튼 클릭
5. 승인 처리 후 **자동으로 이메일 알림**이 신청자에게 발송됩니다

### 반려 처리
1. 검토중 상태의 신청서에서 **반려** 버튼 클릭
2. 반려 모달에서 신청 내용 확인
3. **반려 사유 입력** (필수)
4. **반려** 버튼 클릭
5. 반려 처리 후 **자동으로 이메일 알림**이 신청자에게 발송됩니다 (반려 사유 포함)

### 상세 보기
- 승인/반려된 신청서의 **상세** 버튼 클릭
- 신청자 정보, 모든 신청 데이터, 첨부 파일 다운로드 링크 확인 가능
- 암호화된 필드는 **복호화** 버튼으로 확인 가능 (관리자 전용)

### 신청서 삭제
- 상세 보기에서 **삭제** 버튼으로 신청서 삭제 가능
- 삭제 전 확인 모달이 표시됩니다

### Excel 다운로드
- 신청 목록을 엑셀 파일로 내보내기 가능

## 2. 직원 정보 관리

### 접속
- 관리자 홈에서 **직원 정보 관리** 탭 또는 `/admin/employees` 접속

### 직원 목록
- 상단 검색창으로 **사번 / 이름 / 부서** 검색 가능
- 총 직원 수 표시
- 관리자 계정은 노란색 배지, 일반 직원은 파란색 배지로 구분
- 퇴사 상태 직원은 빨간 "퇴사" 배지 표시, 행이 흐릿하게 표시

### 직원 정보 수정
1. 해당 직원의 **수정** 버튼 클릭
2. 수정 가능한 항목:
   - 이름
   - 이메일 (로그인용) -- 변경 시 Firebase Auth 이메일도 함께 변경됨
   - 부서
   - 직급
   - **관리자 권한** 체크박스
3. **저장** 버튼 클릭

### 비밀번호 관리
1. 직원 수정 모달에서 **비밀번호** 버튼 클릭 (보라색)
2. 두 가지 방법 선택:
   - **lofa1234! 로 초기화**: 기본 비밀번호로 즉시 초기화
   - **직접 설정**: 원하는 비밀번호 직접 입력 후 설정 (6자 이상)
3. 비밀번호 변경 시 **자동으로 이메일 알림**이 해당 직원에게 발송됩니다
   - 초기화 시: 초기화된 비밀번호(lofa1234!)가 이메일에 포함됨
   - 직접 설정 시: 비밀번호가 변경되었으니 관리자에게 문의하라는 안내 발송
   - 직원 이메일이 없으면 알림 미발송 (메시지로 안내)

### 퇴사처리 / 복직처리
- 수정 모달 하단의 **퇴사 처리** 버튼: 직원을 퇴사 상태로 변경 (로그인 불가)
- 퇴사 상태인 직원에게는 **복직 처리** 버튼이 표시됨

### 직원 삭제
- 수정 모달 하단의 **삭제** 버튼 (빨간색) 클릭
- 확인 모달: "직원이름 (사번)을 삭제하시겠습니까?"
- 경고: 로그인 계정(Firebase Auth) + Firestore 데이터 모두 삭제
- **복구 불가능** -- 퇴사처리 후 장기 보관을 권장합니다

## 3. 신청서 관리

### 접속
- 관리자 홈에서 **신청서 관리** 탭 또는 `/admin/forms` 접속

### 신청서 목록
- 등록된 모든 신청 양식이 카드 형식으로 표시
- 각 카드에 아이콘, 제목, 설명, 활성/비활성 상태, 필드 수 표시
- 예산 그룹에 할당된 경우 노란색 배지로 표시

### 새 신청서 추가
1. **+ 폼 추가** 버튼 클릭
2. 제목 입력 (필수)
3. 설명 입력 (선택)
4. **추가** 버튼 클릭
5. 이후 **편집**에서 필드 추가

### 신청서 편집 (필드 구성)
1. 해당 신청서의 **편집** 버튼 클릭 (`/admin/forms/[formId]/edit`)
2. 기본 정보 수정: 폼 제목, 설명
3. **+ 필드 추가**로 입력 항목 추가
4. 각 필드 설정:
   - 필드 이름 (예: "신청금액")
   - 타입 선택 (아래 표 참조)
   - 필수 여부 체크
   - 개인정보 암호화 여부 체크
5. **저장** 버튼 클릭

#### 지원 필드 타입

| 타입 | 설명 |
|------|------|
| 텍스트 | 일반 텍스트 입력 |
| 숫자 | 숫자만 입력 가능 |
| 금액 | 천단위 콤마 자동 포맷 (원) |
| 날짜 | 날짜 선택기 |
| 선택 | 버튼형 선택 (옵션 직접 입력) |
| 라디오 | 라디오 버튼 선택 |
| 장문 | 여러 줄 텍스트 |
| 파일첨부 | JPG, PNG, PDF 등 파일 업로드 (최대 32MB) |
| 계좌번호 | 은행 + 계좌번호 + 예금주 3개 필드 세트 |
| 의료비 내역 | 진료기관/진료일자/금액 테이블 (행 추가/삭제, 자동 합계) |
| 장학금 내역 | 대상자/관계/학교급/금액 테이블 (자동 합계) |
| 자녀 목록 | 자녀 성명/생년월일/비고 테이블 |
| 문화활동 내역 | 활동내용/일정/금액 테이블 (자동 합계) |
| 대부 동의서 | 약관 텍스트 + 동의 체크박스 |

### 신청서 활성화/비활성화
- **활성화**: 직원들에게 메인 화면에 노출 (신청 가능)
- **비활성화**: 직원들에게 숨김 (신청 불가)

### 예산 공유 그룹
여러 신청서가 하나의 한도를 공유하는 그룹을 설정합니다.

1. **+ 그룹 추가** 버튼 클릭
2. 그룹 이름 입력
3. 공유 한도 금액 입력 (원)
4. 한도 주기 선택: 연간 / 월간
5. 포함할 신청서 체크박스로 선택
6. **저장** 버튼 클릭

- 설정된 그룹은 직원 메인 화면 상단에 사용금액/잔여금액/한도가 진행 바와 함께 표시됩니다.
- 그룹 편집/삭제도 가능합니다.

## 4. 알림 설정 (이메일)

관리자 홈에서 이메일 알림 설정을 관리합니다.

### Gmail OAuth 연동 (권장)
1. 관리자 대시보드의 **이메일 설정** 섹션에서 **Gmail OAuth 연동** 클릭
2. Google 계정으로 인증
3. 연동 완료 시 "Gmail 연동 완료" 메시지 표시

### 이메일 수동 설정
- 발신 이메일 주소와 앱 비밀번호를 직접 입력
- Gmail 앱 비밀번호는 Google 계정 > 보안 > 2단계 인증 > 앱 비밀번호에서 생성

### 이메일 알림 발송 시점
| 이벤트 | 자동 발송 여부 | 발송 내용 |
|--------|---------------|-----------|
| 신청서 승인 | 자동 | 승인 안내 메시지 |
| 신청서 반려 | 자동 | 반려 안내 + 반려 사유 |
| 비밀번호 초기화 | 자동 | 초기화된 비밀번호 안내 |
| 비밀번호 직접 설정 | 자동 | 비밀번호 변경 안내 |
| 전체 메일 발송 | 수동 | 관리자가 작성한 제목/내용 |

> 이메일 설정이 되어 있지 않으면 "이메일 설정 필요" 메시지가 표시됩니다.

### 전체 메일 발송
1. 상단 헤더의 **전체 메일 발송** 버튼 클릭
2. 제목과 내용 입력
3. 발송 버튼 클릭
4. 모든 활성 직원(이메일이 있는)에게 일괄 발송

## 5. 공지사항 및 규정집 관리

### 공지사항 관리
- 관리자 홈의 **공지사항** 섹션에서 직접 수정 가능
- 텍스트 입력 후 **저장** 클릭
- 저장 즉시 직원 메인 화면에 반영

- 관리자 홈의 **규정집** 섹션에서 관리
- **버전명** 입력 후 파일 업로드
- 직원 메인 화면에 최신 3건이 표시됨
- 삭제도 가능

## 6. 시스템 설정

### Firebase 프로젝트 전환 (데이터 마이그레이션)
Firebase 계정을 변경해야 할 때 사용합니다. (`/admin/settings`)

> **IT 담당자 또는 개발자만 사용하세요**

**사전 준비사항:**
- 새 Firebase 프로젝트에서 Firestore와 Authentication 먼저 활성화
- 새 프로젝트의 서비스 계정 JSON 정보 준비

**절차:**
1. Firebase 프로젝트 전환 섹션 열기
2. 새 프로젝트 정보 입력:
   - 프로젝트 ID (예: myproject-abc12)
   - 서비스 계정 이메일 (client_email)
   - 서비스 계정 Private Key
3. **데이터 마이그레이션 시작** 클릭
4. 완료 후 `.env.local` 업데이트 및 재배포 필요

**주의:** 마이그레이션 후 모든 비밀번호가 lofa1234!로 초기화됩니다.

## 자주 묻는 질문

**Q. 직원이 로그인을 못 한다고 합니다**
A. 직원 정보 관리에서 해당 직원을 찾아 비밀번호를 초기화하세요. 초기화 시 자동으로 이메일 알림이 발송됩니다.

**Q. 신청을 실수로 승인했어요**
A. 현재 승인 취소 기능은 없습니다. 상세 보기에서 신청서를 삭제하고 신청자에게 재신청을 안내해주세요.

**Q. 특정 직원만 특정 신청서를 볼 수 있게 할 수 있나요?**
A. 현재 버전은 전체 공개/비공개만 지원합니다.

**Q. 예산 그룹은 어떻게 작동하나요?**
A. 예산 그룹에 포함된 모든 신청서의 승인 금액이 합산되어 한도와 비교됩니다. 직원 메인 화면에서 사용금액/잔여금액을 진행 바로 확인할 수 있습니다.

**Q. Google 로그인으로 가입한 직원의 비밀번호는?**
A. Google 로그인 시 추가 정보 입력 단계에서 사내메일 로그인용 비밀번호를 별도 설정합니다. 이 비밀번호도 관리자가 초기화할 수 있습니다.

**Q. 이메일 알림이 안 보내진다고 합니다**
A. 관리자 대시보드의 이메일 설정에서 Gmail OAuth 연동이 되어 있는지 확인하세요. 연동되지 않으면 승인/반려/비밀번호 초기화 시 알림이 발송되지 않습니다.

**Q. 비밀번호 초기화 시 이메일이 안 갑니다**
A. 해당 직원의 이메일 정보가 등록되어 있는지 확인하세요. 이메일이 없으면 알림이 발송되지 않으며, "직원 이메일이 없어 알림 미발송" 메시지가 표시됩니다.
