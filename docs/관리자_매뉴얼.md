# 복지신청 시스템 관리자 매뉴얼

**한국지방재정공제회 복지신청 시스템**
작성일: 2026년 3월

---

## 관리자 접속

1. 시스템 URL 접속 후 로그인
2. 상단 메뉴에서 **관리자** 클릭
3. 관리자 대시보드 진입

> ⚠️ 관리자 권한이 없으면 버튼이 보이지 않습니다.

---

## 1. 신청 관리

### 신청 목록 확인
- **신청 목록** 탭에서 전체 신청 내역 확인
- 검색창으로 이름·사번·항목 검색 가능
- 상태 필터(전체/검토중/승인/반려) 사용 가능

### 신청 처리 방법

| 버튼 | 기능 |
|------|------|
| **상세** | 신청 내용 상세 보기 |
| **승인** | 신청 승인 처리 |
| **반려** | 반려 사유 입력 후 반려 |
| **삭제** | 신청 영구 삭제 (복구 불가) |

### 신청 승인 절차
1. 신청 목록에서 **상세** 버튼 클릭
2. 신청 내용 확인
3. **승인** 또는 **반려** 선택
4. 반려 시 사유 입력 필수

### Excel 다운로드
- **Excel 다운로드** 버튼 클릭
- 전체 신청 내역이 CSV 파일로 다운로드

---

## 2. 직원 관리

**직원 관리** 탭에서 전체 직원 조회·관리 가능

### 직원 정보 수정
1. 해당 직원의 **수정** 버튼 클릭
2. 이름·부서·직급·관리자 권한 수정
3. **저장** 버튼 클릭

### 비밀번호 관리 ⭐
1. 해당 직원의 **비밀번호** 버튼 클릭
2. 두 가지 방법 선택:
   - **lofa1234! 로 초기화**: 기본 비밀번호로 즉시 초기화
   - **직접 설정**: 원하는 비밀번호 직접 입력 후 설정
3. 초기화 후 반드시 직원에게 새 비밀번호 알려주세요

### 퇴사처리 / 복직처리
- **퇴사** 버튼: 직원을 퇴사 상태로 변경 (로그인 불가)
- **복직** 버튼: 퇴사 직원을 다시 활성화

### 직원 삭제 ⚠️
- **삭제** 버튼: 직원 계정 완전 삭제
- 로그인 계정 + Firestore 데이터 모두 삭제
- **복구 불가능** — 신중하게 사용하세요

---

## 3. 폼(신청 양식) 관리

상단의 **폼 관리** 버튼으로 이동

### 폼 목록 화면
- 등록된 모든 신청 양식 확인
- 활성/비활성 상태 표시

### 새 폼 추가
1. **+ 폼 추가** 버튼 클릭
2. 제목·설명 입력
3. **추가** 버튼 클릭
4. 이후 **편집** 에서 필드 추가

### 폼 편집 (필드 구성)
1. **편집** 버튼 클릭
2. **+ 필드 추가** 로 입력 항목 추가
3. 각 필드 설정:
   - 필드 이름 (예: "신청금액")
   - 타입: 텍스트/숫자/날짜/선택/장문
   - 필수 여부 체크
4. **저장** 버튼 클릭

### 폼 활성화/비활성화
- **활성화**: 직원들에게 노출됨 (신청 가능)
- **비활성화**: 직원들에게 숨김 (신청 불가)

---

## 4. 설정

**설정** 버튼으로 이동

### 예산 설정
1. **연간 예산** 입력 (원 단위)
2. **사용 예산** 입력 (승인된 금액 합계)
3. **저장** 클릭
4. 홈 화면에서 예산 현황 확인 가능

### Firebase 프로젝트 전환 (데이터 마이그레이션)
Firebase 계정을 변경해야 할 때 사용합니다.

> ⚠️ **IT 담당자 또는 개발자만 사용하세요**

1. **Firebase 프로젝트 전환** 섹션 열기
2. 새 Firebase 프로젝트 정보 입력:
   - 프로젝트 ID
   - 서비스 계정 이메일
   - 서비스 계정 Private Key
3. **데이터 마이그레이션 시작** 클릭
4. 완료 후 개발자에게 `.env.local` 업데이트 요청

---

## 5. 주요 주의사항

| 항목 | 주의사항 |
|------|----------|
| 비밀번호 초기화 | 직원에게 변경 사실 알림 필수 |
| 직원 삭제 | 복구 불가. 퇴사처리 후 장기 보관 권장 |
| 폼 비활성화 | 진행 중인 신청에는 영향 없음 |
| 예산 설정 | 정확한 금액 입력 필요 |

## ❓ 자주 묻는 질문

**Q. 직원이 로그인을 못 한다고 합니다**
A. 직원 관리 탭에서 해당 직원 찾아 비밀번호 초기화 후 안내

**Q. 신청을 실수로 승인했어요**
A. 현재 승인 취소 기능 없음. 직접 신청자에게 연락하여 처리

**Q. 특정 직원만 특정 폼을 볼 수 있게 할 수 있나요?**
A. 현재 버전은 전체 공개/비공개만 지원. 부서별 필터는 추후 기능 추가 예정
