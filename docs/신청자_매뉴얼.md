# LOFA 복지시스템 사용 매뉴얼 (일반 직원용)

**한국지방재정공제회 사내근로복지기금 신청 시스템**
최종 업데이트: 2026년 3월

---

## 시작하기

### 시스템 접속 방법
1. 웹 브라우저(크롬, 엣지 등)를 엽니다
2. 주소창에 시스템 URL을 입력합니다
3. 로그인 화면이 나타납니다

---

## 1. 로그인

### 이메일/비밀번호 로그인
1. **이메일 주소** 입력 (회사 이메일)
2. **비밀번호** 입력
3. **로그인** 버튼 클릭

### Google 계정으로 로그인
1. **Google 계정으로 로그인** 버튼 클릭
2. Google 계정 선택 및 인증
3. 처음 Google 로그인 시 추가 정보 입력 화면으로 이동합니다

### 초기 비밀번호
- 초기 비밀번호는 `lofa1234!` 입니다
- 처음 로그인 후 반드시 비밀번호를 변경해주세요

### 로그인이 안 될 때
- 이메일 주소를 다시 확인해주세요
- 비밀번호를 여러 번 틀리면 관리부 담당자에게 초기화를 요청하세요

---

## 2. 회원가입 (신규 직원)

처음 시스템을 사용하는 경우 회원가입이 필요합니다.

### 방법
1. 로그인 화면에서 **회원가입** 클릭
2. 아래 정보 입력:
   - 사번, 이름
   - 부서, 직급
   - 이메일 (기본값: @lofa.or.kr)
   - 입사일, 전화번호
   - 비밀번호 (6자 이상), 비밀번호 확인
3. **가입하기** 버튼 클릭

### Google 계정으로 첫 로그인 시
1. Google 로그인 후 **추가 정보 입력** 화면이 나타납니다
2. 사번, 이름, 부서, 직급 등 필수 정보 입력
3. **사내메일 로그인용 비밀번호** 설정 (6자 이상)
4. 제출하면 가입이 완료됩니다

---

## 3. 메인 화면 (홈)

로그인 후 보이는 메인 화면에는 다음 내용이 표시됩니다.

### 올해 내 신청 현황
- 최근 6건의 신청 내역이 테이블로 표시됩니다
- 신청일시, 항목, 금액, 상태, 비고를 확인할 수 있습니다
- **검토중/반려** 상태인 건은 **수정** 및 **삭제**가 가능합니다
- **전체보기** 버튼으로 전체 신청현황 페이지로 이동합니다

### 예산 공유 그룹 현황
- 여러 복지 항목이 하나의 예산을 공유하는 경우, 상단에 그룹별 사용금액/잔여금액/한도가 진행 바와 함께 표시됩니다

### 복지 항목 카드
- 신청 가능한 복지 항목이 카드 형태로 나열됩니다
- 각 카드에 아이콘, 제목, 설명, 올해 승인 금액이 표시됩니다
- 원하는 항목의 카드를 클릭하면 신청서 작성 페이지로 이동합니다

### 공지사항
- 관리자가 등록한 공지사항이 표시됩니다

### 복지기금 규정집
- 최신 규정 문서 3건이 표시됩니다
- 첨부 파일을 다운로드할 수 있습니다

---

## 4. 복지 신청하기

### 신청 방법
1. 메인 화면에서 원하는 복지 항목 카드 클릭
2. 신청서 작성 페이지에 진입합니다

### 신청서 구성
1. **신청인 정보** (자동 입력): 성명, 사번, 부서, 직급, 입사일, 전화번호
2. **신청 내용**: 항목별로 다른 입력 필드가 표시됩니다

### 입력 항목 종류
| 종류 | 설명 |
|------|------|
| 텍스트/숫자 | 일반 텍스트 또는 숫자 입력 |
| 금액 | 자동으로 천단위 콤마가 붙습니다 (예: 1,000,000 원) |
| 날짜 | 달력에서 날짜 선택 |
| 선택/라디오 | 제시된 옵션 중 하나 선택 |
| 파일 첨부 | JPG, PNG, PDF 등 증빙서류 업로드 (최대 32MB) |
| 계좌번호 | 은행 선택 + 계좌번호 + 예금주 입력 |
| 내역 테이블 | 의료비/장학금/문화활동 등의 세부 내역을 행 단위로 추가 (자동 합계) |

### 개인정보 수집 동의
- 신청서 하단에 **개인정보 수집 및 이용 동의** 체크가 필요합니다
- 수집항목: 성명, 사번, 부서, 직급, 전화번호, 입사일, 계좌번호, 신청금액/사유, 증빙서류
- 보유기간: 지원 종료 후 5년

### 제출
1. 모든 필수 항목 작성 확인
2. 개인정보 동의 체크
3. **신청서 제출** 버튼 클릭
4. "신청이 완료되었습니다" 메시지 확인
5. 담당자 검토 후 결과를 안내받을 수 있습니다

---

## 5. 내 신청현황 확인

### 접속 방법
- 상단 메뉴에서 **내 신청현황** 클릭
- 또는 메인 화면 신청 현황의 **전체보기** 클릭

### 필터 기능
- **상태 필터**: 전체 / 검토중 / 승인 / 반려 (각 건수 표시)
- **연도 필터**: 드롭다운으로 연도 선택

### 신청 목록
각 신청서가 카드 형태로 표시됩니다:
- 항목명 + 상태 배지
- 신청 날짜
- 반려된 경우 반려 사유가 빨간 배경으로 표시

### 상태 안내
| 상태 | 색상 | 의미 |
|------|------|------|
| 검토중 | 노란색 | 담당자가 확인 중입니다 |
| 승인 | 초록색 | 신청이 승인되었습니다 |
| 반려 | 빨간색 | 신청이 반려되었습니다 (사유 확인) |

### 신청서 수정/삭제
- **검토중** 또는 **반려** 상태의 신청서는 **수정** 및 **삭제**가 가능합니다
- 수정 시 기존 신청서 양식에 입력했던 내용이 미리 채워진 상태로 열립니다
- **승인** 상태의 신청서는 수정/삭제가 불가합니다

### 상세 보기
- 신청서 카드 클릭 시 상세 내용을 팝오버로 확인할 수 있습니다
- 반려 사유가 있으면 빨간 박스로 강조 표시됩니다

---

## 6. 개인정보 수정

### 접속 방법
- 상단 네비게이션 바 오른쪽의 설정(톱니바퀴) 아이콘 클릭

### 개인정보 수정
수정 가능한 항목:
- 성명, 부서, 직급, 입사일, 회사 이메일, 전화번호

읽기 전용 항목:
- 사번, 로그인 이메일

수정 후 **저장하기** 버튼 클릭

### 비밀번호 변경
1. 현재 비밀번호 입력
2. 새 비밀번호 입력 (6자 이상)
3. 새 비밀번호 확인 입력
4. **비밀번호 변경** 버튼 클릭

> Google 계정으로 로그인한 경우, 비밀번호는 Google 계정 설정에서 변경해야 합니다.

## 자주 묻는 질문 (FAQ)

**Q. 비밀번호를 잊어버렸어요**
A. 관리부 담당자에게 연락하면 비밀번호를 초기화해드립니다. 초기화 비밀번호는 lofa1234! 입니다.

**Q. 신청한 항목을 취소할 수 있나요?**
A. 검토중 또는 반려 상태에서는 내 신청현황 페이지에서 직접 삭제할 수 있습니다. 승인된 건은 담당자에게 연락해주세요.

**Q. 반려되면 다시 신청할 수 있나요?**
A. 네, 반려된 신청서를 수정하여 재제출하거나, 새로 신청할 수 있습니다.

**Q. 예산 한도가 표시되는데 이게 뭔가요?**
A. 일부 복지 항목은 연간/월간 예산 한도가 있습니다. 메인 화면 상단의 예산 그룹 현황에서 사용금액과 잔여금액을 확인할 수 있습니다.

**Q. 파일 첨부가 안 돼요**
A. JPG, PNG, PDF 파일만 지원하며, 최대 32MB까지 업로드 가능합니다. 파일 크기를 확인해주세요.

**Q. Google 로그인과 이메일 로그인 둘 다 사용할 수 있나요?**
A. 네, Google로 가입한 경우에도 사내메일 비밀번호를 설정하면 이메일로도 로그인할 수 있습니다.
