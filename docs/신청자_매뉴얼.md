# 복지신청 시스템 사용 매뉴얼 (일반 직원용)

**한국지방재정공제회 복지신청 시스템**
작성일: 2026년 3월

---

## 🚀 시작하기

### 시스템 접속 방법
1. 웹 브라우저(크롬, 엣지 등)를 엽니다
2. 주소창에 시스템 URL을 입력합니다
3. 로그인 화면이 나타납니다

---

## 1. 로그인

### 방법
1. **사번** 입력 (예: `2121`)
2. **비밀번호** 입력
3. **로그인** 버튼 클릭

### 초기 비밀번호
- 초기 비밀번호는 `lofa1234!` 입니다
- 처음 로그인 후 반드시 비밀번호를 변경해주세요

### 로그인이 안 될 때
- 사번을 다시 확인해주세요
- 비밀번호를 여러 번 틀리면 담당자에게 초기화를 요청하세요
- 담당자 연락처: 관리부

---

## 2. 회원가입 (신규 직원)

처음 시스템을 사용하는 경우 회원가입이 필요합니다.

### 방법
1. 로그인 화면에서 **회원가입** 클릭
2. 아래 정보 입력:
   - 사번
   - 이름 (성명)
   - 부서
   - 직급
   - 비밀번호 (6자 이상)
3. **가입하기** 버튼 클릭

---

## 3. 복지 신청하기

### 방법
1. 로그인 후 **홈 화면** 확인
2. 오른쪽 **복지 신청** 목록에서 원하는 항목 클릭
3. 신청서 작성 후 **신청하기** 버튼 클릭
4. 완료 메시지 확인 → 담당자 검토 대기

### 신청 가능한 복지 항목 예시
| 항목 | 설명 |
|------|------|
| 경조사비 | 결혼, 출산, 사망 등 |
| 의료비 지원 | 본인 및 가족 의료비 |
| 자녀 학자금 | 자녀 교육비 지원 |
| 여름 휴양 지원 | 여름철 휴가비 |

> ※ 신청 항목은 관리자 설정에 따라 변경될 수 있습니다.

---

## 4. 내 신청현황 확인

### 방법
1. 상단 메뉴에서 **내 신청현황** 클릭
2. 신청 내역 목록 확인
3. 각 항목 클릭 시 상세 내용 확인 가능

### 상태 안내
| 상태 | 의미 |
|------|------|
| 🟡 검토중 | 담당자가 확인 중입니다 |
| 🟢 승인 | 신청이 승인되었습니다 |
| 🔴 반려 | 신청이 반려되었습니다 (사유 확인) |

---

## 5. 로그아웃

오른쪽 상단의 **로그아웃** 버튼을 클릭합니다.

> ⚠️ 공용 컴퓨터 사용 시 반드시 로그아웃하세요.

---

## ❓ 자주 묻는 질문 (FAQ)

**Q. 비밀번호를 잊어버렸어요**
A. 관리부 담당자에게 연락하면 비밀번호를 초기화해드립니다.

**Q. 신청한 항목을 취소할 수 있나요?**
A. 검토중 상태에서는 담당자에게 연락하여 취소 요청하세요.

**Q. 반려되면 다시 신청할 수 있나요?**
A. 네, 반려 사유를 확인 후 수정하여 재신청 가능합니다.

**Q. 예산이 부족하면 어떻게 되나요?**
A. 예산 소진 시 신청이 제한될 수 있습니다. 홈 화면의 예산 현황을 확인하세요.
