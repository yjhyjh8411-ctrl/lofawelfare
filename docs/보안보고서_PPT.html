데이터가 도중에 새지 않나요?
전송 암호화 및 저장 보안
  • 모든 통신은 HTTPS (TLS 1.3)로 암호화 — 도청 불가
  • 비밀번호는 암호화 저장 — 관리자도 평문 확인 불가
  • Firebase가 SSL 인증서 자동 관리 — 만료 걱정 없음
  • HTTP 접속 시 자동으로 HTTPS로 전환
  • 서울 리전에 데이터 저장 — 해외 반출 없음

🔒 쉬운 비유

일반 편지 대신 봉인된 특수 봉투(HTTPS)를 사용합니다. 중간에 누가 가로채도 내용을 읽을 수 없습니다. 마치 금고차가 현금을 나르는 것처럼, 데이터도 암호화된 경로로만 이동합니다.
