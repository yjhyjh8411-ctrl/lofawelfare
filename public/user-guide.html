1단계 회원가입 & 로그인

처음 사용하시는 분은 회원가입부터!

1

회원가입 페이지 접속

로그인 화면에서 "회원가입" 버튼을 클릭합니다.

2

정보 입력

사번, 이름, 부서, 직급, 이메일(@lofa.or.kr), 입사일, 전화번호를 입력합니다.
비밀번호는 6자 이상으로 설정해주세요.

3

로그인

가입한 이메일과 비밀번호로 로그인합니다.
Google 계정으로도 로그인할 수 있습니다.

💡 Tip: Google 로그인은 처음 사용 시 추가 정보(사번, 부서 등)를 한 번만 입력하면 됩니다.

2단계 메인화면 살펴보기

로그인하면 바로 보이는 화면입니다

📊

올해 내 신청 현황

올해 신청한 내역이 표로 보입니다. 검토중/승인/반려 상태를 한눈에 확인하세요.

💰

한도 현황 바

항목 그룹별 연간 한도와 사용/잔여 금액이 프로그레스 바로 표시됩니다.

📋

복지 항목 카드

신청 가능한 복지 항목이 카드 형태로 나열됩니다. 카드를 클릭하면 바로 신청 페이지로 이동!

📢

공지사항 & 규정집

하단에서 공지사항 확인 및 규정집 다운로드가 가능합니다.

💡 신청 양식 안내:

- 첨부파일은 영수증, 증빙서류 등을 업로드해주세요
- 계좌번호는 암호화되어 안전하게 저장됩니다

4단계 신청 상태 확인

신청 후 결과를 확인합니다

⏳ 검토중
✓ 승인
✕ 반려
⏳

검토중

제출 완료 후 관리자가 검토 중인 상태입니다. 잠시 기다려주세요.

✅

승인

신청이 승인되었습니다. 이메일로 알림이 발송됩니다.

❌

반려

반려 사유를 확인하고, 수정하여 재신청할 수 있습니다.

💡 "내 신청현황" 페이지에서 년도별 필터링과 상태별 필터링으로 쉽게 찾을 수 있습니다.

신청 수정 & 삭제

잘못 입력했거나 변경이 필요할 때

✏️
수정하기
검토중 또는 반려 상태인 신청만 수정 가능합니다.

"수정" 버튼 클릭 → 내용 수정 → 다시 제출
🗑️
삭제하기
검토중 또는 반려 상태인 신청만 삭제 가능합니다.

"삭제" 버튼 클릭 → 확인 → 완전 삭제

⚠️ 주의: 이미 승인된 신청은 수정/삭제가 불가합니다. 승인 후 변경이 필요하면 사무국에 문의해주세요.
